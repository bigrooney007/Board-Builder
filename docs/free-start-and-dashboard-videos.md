# Free entry and dashboard walkthroughs

The four offer homepages use **Get Started for Free** for their main calls to action. Each button opens the existing first form. The main homepage's four offer cards also link directly to those forms:

| Offer | First form |
| --- | --- |
| Board Recruitment | `/recruit/start` |
| Board Fundraising | `/board-fundraising/start` |
| Strategic Planning | `/strategic-planning/start` |
| Board Recommitment | `/board-recommitment/start` |

First-form submit buttons say **Continue for Free**. The saved-question journeys still lead to their existing video and payment pages.

## Dashboard walkthrough links

Each of the four dashboards has **Watch How To Use This Dashboard** near the top. The video opens in a new tab so the user can return to their dashboard.

In **Admin → Videos → Dashboard Walkthrough Videos**, save a YouTube URL or video ID for each offer. These four fields are separate from the payment and onboarding videos. Changes use the existing database settings and appear on refresh or when the dashboard regains focus.

Until a dedicated walkthrough is saved, the link uses that offer's saved onboarding video. If neither video is available, the dashboard displays **Dashboard video coming soon**.

The four payment videos remain in **Admin → Videos → Videos For The Four Offers**.
